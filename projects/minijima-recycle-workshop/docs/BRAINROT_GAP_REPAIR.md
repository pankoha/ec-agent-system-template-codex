# 「リサイクル島の大冒険」全面改修

## 方針

Brainrot系の過剰刺激・喪失ストレス・課金圧力は採用せず、以下の長所だけを子ども向けに翻訳する。

- 行動直後に数字・姿・場所が変わる
- 次に欲しい作品・エリア・景観が見える
- 特別な素材を一目で判別できる
- 小さな成長と大きな達成を別々の強さで祝う

## 最優先10項目

- [x] 素材接近時に名前・希少度・操作を表示
- [x] 工作完成時に作品を大きなカードで表示
- [x] ミッションクリアを全画面で祝福
- [x] 次の作品・エリア・島変化を予告
- [x] きれい度のBefore/Afterをクリア画面に表示
- [x] エコロボを中央の案内役として追加
- [x] 16エリアを角張った平面から丸い立体地形へ変更
- [x] 鳥・蝶・魚・島民を全エリアへ追加
- [x] レア素材へ希少度、色付き輪郭、発光、ボーナスを追加
- [x] 「拾う→作る→島が変わる」を獲得表示、完成画面、成長予告で接続

## 表示階層

- 小さな成功: 素材獲得バナー（3秒）
- 中程度の成功: 工作完成カード（「つぎへ」まで保持）
- 大きな成功: ミッションクリア全画面、紙吹雪、きれい度変化、新エリア、次目的

## ビジュアル

- 仮タイトル: リサイクル島の大冒険
- 主役: エコロボ
- 通常素材: 現行の読みやすいアニメ輪郭
- レア素材: 黄、紫、ピンクの段階的な光
- 島: 丸い土台、高台、7個以上の景観物、固有ランドマーク
- 生き物: 中央島と各エリアで往復移動
