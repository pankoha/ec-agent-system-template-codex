# 工作ミニゲームと3層ヒント

## 3層ヒント

1. 常時表示: 今行う操作を一文だけ表示する。
2. 自動ヒント: 初めての操作で6秒、習得済み操作で10秒止まると、具体的なヒントと点滅を表示する。
3. 詳細説明: 「？ くわしく」から、操作方法・成功条件・失敗時の扱いをいつでも確認できる。

失敗しても材料を失わない。工程を閉じた場合も、サーバーへ工作要求を送らないため材料は消費されない。

## 作品別の工作

| 作品 | 工作1 | 工作2 |
|---|---|---|
| ボトルプランター | パーツをはめる | 色を選ぶ |
| 空き缶スツール | ハンドルを3回回す | 模様を選ぶ |
| パッチワークランプ | 材料を順番に置く | 黄色い時間にボタンを押す |
| リサイクルベンチ | 設計図と同じ形を探す | パーツを組み合わせる |
| エコロボ | 壊れた場所を修理する | ステッカーを選ぶ |

色・模様・ステッカーには不正解を設けない。設計図と材料順だけは再挑戦が必要だが、材料は減らない。
